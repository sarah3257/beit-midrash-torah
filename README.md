# בית המדרש שלי

ספרייה אישית לחידושי תורה בעברית, לפי מסכת, פרק ודף בבבלי או לפי נושאים אישיים.

## התקנה ושימוש

אתר: https://beit-midrash-torah.vercel.app

הוראות התקנה: https://beit-midrash-torah.vercel.app/install.html

הורדת Windows: https://github.com/sarah3257/beit-midrash-torah/releases/latest

המתקין מתאים ל־Windows 10/11 במעבדי Intel/AMD ‏64 ביט. אין צורך בכלי פיתוח. לאחר ההתקנה מפעילים מקיצור הדרך. כתיבה, חיפוש, ייבוא Word וגיבוי עובדים ללא אינטרנט.

כל התקנה חדשה שומרת ספרייה נפרדת בתיקיית המשתמש ב־Windows, תחת AppData/Roaming/chidushei-torah/library. הכתבים נשארים גם אחרי הסרת התוכנה. בתוכנה שהותקנה במחשב המפתח קיים desktop-config.json שמפנה לספרייה המקורית; הוא אינו נכלל במתקין המופץ.

## ענן וסנכרון ידני

האתר משתמש ב־Vercel ובמסד PostgreSQL של Neon. הספרייה בענן פרטית לחשבון. חשבון נוצר באמצעות דוא״ל וסיסמה של לפחות 12 תווים. אימות כתובת ושחזור סיסמה בדוא״ל אינם פעילים כרגע; חשוב לשמור את הסיסמה ואת גיבויי הכתבים.

בתוכנת המחשב לוחצים על **העלה עדכונים לאתר**, מתחברים לאותו חשבון ולוחצים על **העלה עדכונים לאתר וסנכרן**. הפעולה מעלה כתבים וקובצי Word מקוריים וגם מורידה כתבים מהענן. היא אינה מפרסמת כתבים במאגר הקוד. הכתיבה המקומית אינה תלויה בחשבון או בחיבור לרשת.

אם אותו מסמך נערך בשני מקומות מאז הסנכרון האחרון, נשמר עותק נוסף עם הסיומת ״עותק מהסנכרון״. מחיקה היא העברה לסל מחזור, וניתן לשחזר. מומלץ לסנכרן לפני מעבר בין מחשבים. טיוטות שנכתבו בזמן ניתוק מהאתר עצמו נשמרות בדפדפן; לעבודה מלאה ללא אינטרנט משתמשים בתוכנה.

מגבלות לכל חשבון בענן: ספריית טקסט וגרסאות עד 25MB, קובצי מקור עד 100MB, עד 10,000 מסמכים. קובץ Word בודד עד 15MB. בהעלאה נכללות הגרסאות האחרונות שמתאימות למגבלת הבקשה; הגרסאות הקודמות במחשב נשמרות בנפרד. המסלולים החינמיים של הספקים כפופים למכסות שלהם. לא נרכשו מסלולים בתשלום.

## גיבוי

ב״גיבוי והגדרות״ אפשר להוריד ZIP עם כתבים וגרסאות וקובצי מקור, או JSON לשחזור מסמכים חסרים. שחזור JSON מוסיף מסמכים ואינו מחליף מסמכים קיימים. לשחזור מלא במחשב, סוגרים את התוכנה ואת השרת ומחליפים את library.json ואת תיקיית uploads מתוך גיבוי ZIP, לאחר שמירת עותק של הספרייה הנוכחית. אין לערוך את קובצי הנתונים בזמן שהתוכנה פתוחה.

במחשב נוצר גיבוי יומי לפני השינוי הראשון בתיקיית backups. יש לשמור גם עותק בכונן נפרד.

## פיתוח

Node 24 ומעלה. התקנה: `npm ci`. הפעלת אתר מקומי: `npm start`. בדיקות: `npm test`. הפעלת חלון שולחן עבודה: `npm run desktop`. בניית מתקין: `npm run build:installer` במחשב Windows. פרסום גרסה חדשה: עדכון version וקישור ההורדה ב־public/install.html, בנייה, בדיקה, דחיפה ל־GitHub והרצת `node scripts/publish-release.mjs`.

קובצי נתונים, סודות, סביבת Node המקומית ותוצרי בנייה מוחרגים מ־Git ומ־Vercel. המתקין מכיל רשימת קבצים מפורשת ואינו כולל נתוני משתמש.

## פריסת ענן

הפרויקט ב־Vercel מחובר למאגר GitHub. יש לחבר Neon במסלול החינמי, למשוך משתני סביבה לקובץ .env.local, ולהגדיר DATABASE_URL, BETTER_AUTH_SECRET ו־BETTER_AUTH_URL. יש להריץ `npm run cloud:migrate` לפני פתיחת הרשמה ולפרוס לייצור. המפתח BETTER_AUTH_SECRET חייב להישאר קבוע; אין להכניס אותו לקוד או למתקין. בקשות למסמכים תמיד קשורות לחשבון המאומת; עדכון ספרייה נעשה בעסקת מסד נתונים עם נעילת שורה.

מסד הנתונים הוקם וחובר לפרויקט. ב־12.10.2026 עברו בדיקות מול סביבת הייצור: הרשמה, התחברות, סנכרון ממחשב לענן, שמירת קובצי Word מקוריים, עריכה במקביל ושמירת שני נוסחים, הורדה למחשב נוסף, הפרדת חשבונות וסל מחזור. נתוני הבדיקה הזמניים הוסרו בסיום.
